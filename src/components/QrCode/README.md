# QrCode

Renders a QR code as an inline SVG for any string value, using
[`qrcode-generator`](https://www.npmjs.com/package/qrcode-generator).

## Props

| Prop | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `value` | `string` | yes | — | Data encoded in the QR code. |
| `size` | `number` | no | `256` | Width/height in pixels. |
| `errorCorrectionLevel` | `'L' \| 'M' \| 'Q' \| 'H'` | no | `'M'` | QR error-correction level (higher = more redundancy, denser code). |

## Usage

```tsx
import { QrCode } from 'lcano-react-ui';

<QrCode value="https://example.com/invite/abc123" size={200} />
```

## Notes

- Not theme-aware — the SVG is always rendered as generated by `qrcode-generator` (black on
  transparent/white), unaffected by `VariantColor`/`ThemeProvider`.
- Regenerates the SVG (`useMemo`) only when `value` or `errorCorrectionLevel` change.
